# 同路行微信小程序接入说明

当前小程序采用独立 NestJS API，不使用微信云开发。

## 本地联调

1. 在 `apps/api` 安装依赖并准备 PostgreSQL。
2. 设置 `API_BASE_URL` 为后端 HTTPS 地址；微信开发工具中将其加入 request 合法域名。
3. 登录后先调用 `POST /auth/phone` 完成手机号验证；未验证用户只能浏览。
4. 所有写操作携带 `x-user-id`（当前为开发占位，正式环境替换为微信登录态）和写请求幂等键。

## 平台降级

叫车暂不依赖真实滴滴/高德凭据。后端返回 `launch.supported=false` 时，小程序复制起点、终点和时间，并引导用户手动打开第三方 App。

订单截图上传到 Kodo 私有桶后只把对象 key 传给 API；前端不保存真实支付凭据。
