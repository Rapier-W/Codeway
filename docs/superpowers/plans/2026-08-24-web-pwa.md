# 同路行 Web/PWA 前端 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可运行、可测试、手机优先的同路行 Vue Web/PWA P0 前端骨架，以 Mock/HTTP Adapter 与尚未部署的后端解耦。

**Architecture:** `apps/web` 是独立 Vite 应用。路由页面只依赖 Pinia stores 和 typed API 门面；Mock client 提供可演示数据，HTTP client 将 Cookie 请求集中在一处。App shell 负责导航、响应式布局、PWA 提示和统一反馈。

**Tech Stack:** Vue 3、Vite、TypeScript、Vue Router、Vant、Pinia、Vitest、vite-plugin-pwa。

**Spec:** `docs/superpowers/specs/2026-08-24-web-pwa-design.md`

## Global Constraints

- 仅创建 `apps/web` 和必要根级协同记录；不得修改 NestJS 后端业务实现。
- 手机优先：320px 可用、44×44px 触控目标、48px 主按钮、`100dvh` 和安全区底部留白。
- Pinia 不保存 token、手机号、订单图片或 SOS 位置；HTTP 始终 Cookie credentials。
- 业务最终状态只能来自 Adapter；每个写操作生成并传递 idempotency key。
- PWA 仅预缓存静态构建资源，不配置 API/敏感运行时缓存。
